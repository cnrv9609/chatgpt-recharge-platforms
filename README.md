## ChatGPT Plus、Pro 5x 和 Pro 20x 怎么选？

如果你只是想正常使用 ChatGPT，Plus 通常已经覆盖大多数人的需求。适合的场景包括：

- 日常写作、翻译和资料整理；
- 偶尔上传 PDF、表格或图片；
- 使用高级模型完成工作和学习任务；
- 每天使用，但不是连续高强度调用。

Pro 5x 更适合已经明显遇到额度限制的人。例如你每天需要处理大量长文档、连续进行代码调试，或者经常使用高消耗模型。它的价值主要来自更高的使用空间，而不是“回答质量自动变成五倍”。

Pro 20x 则面向重度用户。购买之前最好先确认自己的实际用量，否则容易出现一个典型情况：套餐档位买得很高，实际使用强度却只够 Plus。数字看起来很有冲击力，账单也会很有存在感。

公开对比资料曾将 ChatGPT Plus、Pro 5x 和 Pro 20x 分别与 Claude Pro、Max 5x、Max 20x 放在同一档位比较，并记录官方基准价格约为 20、100 和 200 美元每月。不过这些是上游官方方案的基准价，不等于 BeWild 当前收银台价格，最终仍应以付款页面显示为准。

## 购买流程：从账号登录到会员生效

以 ChatGPT Plus 为例，官方帮助中心给出的流程大致是：

### 1. 选择 ChatGPT 产品

进入订阅页后，选择 ChatGPT，再选择 Plus、Pro 5x 或 Pro 20x。页面可能会先让你选择单月订阅或长期订阅，然后再选择具体档位。

单月方案适合首次尝试。多月方案通常会显示更低的月均价格，但要特别看清楚是否属于按月自动扣款或预存式连续订阅。

### 2. 登录自己的 ChatGPT 账号

平台需要确认要开通的是哪个账号。登录时应使用你准备长期使用的账号，不要因为邮箱相似就随便提交。

官方教程提醒，账号邮箱核对错误后，已开通的权益通常无法简单转移到另一个账号。

### 3. 提交平台要求的账号凭证

ChatGPT Plus 的教程要求从已登录状态获取一段 Session 信息；Pro 5x 的流程还要求使用浏览器扩展导出 Cookie。Claude 和 Gemini 也分别要求导出 Cookie 或账号相关信息。

这一环节需要认真看页面说明：

- 只在官方页面登录；
- 不要把 Session 或 Cookie 发给客服以外的第三方；
- 不要把凭证截图发布到群聊、论坛或社交平台；
- 订阅完成后及时退出不必要的浏览器扩展；
- 如果流程异常，不要反复提交旧凭证。

Cookie 和 Session 本质上是账号登录凭证，不是普通优惠码。平台教程本身也多次提醒用户保密，不要转发给他人。

### 4. 核对邮箱和金额后付款

确认页面显示的邮箱、产品名称、订阅时长和优惠后金额。付款方式可能包括微信支付、银行卡或 Stripe 支持的其他方式，具体选项以当次收银台为准。

付款后不要因为几分钟没有生效就立刻重复下单。官方教程给出的 ChatGPT 处理时间通常约为 5 至 15 分钟，Pro、Claude 或 Gemini 某些订单可能需要更长时间。

### 5. 在订单页确认状态

付款完成后，进入平台订单页面查看状态。不要只看支付成功通知，还要确认 ChatGPT 账号内的套餐是否已经变化。

如果平台显示订单完成，但 ChatGPT 仍然显示免费版，官方帮助中心建议核对登录账号、订单信息和当前套餐，并联系在线客服处理。重复付款通常不会让处理速度变快，只会让退款和订单核对更麻烦。

## 退款和自动续费要提前看清楚

BeWild 的退款规则并不是“任何情况都可以退”。官方说明显示，已经完成履约且权益生效的订单，因选错产品、选错套餐、误操作购买或购买后不想使用，原则上不支持退款、退换或取消。订单仍在处理中、订阅未生效，或多月套餐存在未生效月份时，可以联系客服核实是否符合退款条件。

多月订阅也要特别小心。官方 ChatGPT 和 Claude 教程都提醒，部分长期订阅会按月自动续费或使用预存金额继续开通。如果你在上游 ChatGPT 或 Claude 页面自行点击取消，可能影响尚未使用的预付月份。

Gemini 的规则又不一样。官方帮助中心显示，Gemini 不支持在有效订阅期间提前续费，也不能直接在套餐内升级到更高档；通常需要等待当前订阅结束，再重新购买。

因此，购买前最好把以下内容截图保存：

- 商品名称；
- 订阅周期；
- 原价和优惠后价格；
- 自动续费说明；
- 退款规则；
- 订单编号；
- 最终付款金额。
